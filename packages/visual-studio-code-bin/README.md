# visual-studio-code-bin

Visual Studio Code (vscode): Editor for building and debugging modern web and cloud applications (official binary version)

The recipe is omacom-io/omarchy-pkgs' `visual-studio-code-bin` PKGBUILD, unchanged, at the omarchy-pkgs
revision in upstream-lock.json. Omarchy's Install menu adds it; upstream publishes the
package only in Omarchy's own repository, which the ARM port does not use, so the
port builds it from the pinned sources.
